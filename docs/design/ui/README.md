# UI / UX 設計定義

**狀態:** v1.1(進入流程與導覽外殼已實作驗證) · **最後更新:** 2026-08-07 · **負責人:** claustrum

依 dev-standards「App UI 以 Claude 設計、接近產品化」與使用者指示「**進入完整開發前先定義好
UI/UX**」,本目錄收錄 claustrum App 的介面與互動定義。實作(Jetpack Compose)須對照本稿。

> **註:** 本目錄為**設計定義**(非程式模組),故不套用 `_template/` 的 SA/SD;各 UI 對應的
> 程式行為/測試落在其功能模組([`android`](../android/SD.md)、[`model`](../model/SD.md)、
> [`vlm`](../vlm/SD.md))。

## 互動原型

[`claustrum-uiux.html`](claustrum-uiux.html) —— 自包含互動原型(近單色 Tesla / Optimus 科技感)。
可直接以瀏覽器開啟;明暗色皆一等公民。

## 設計語彙(Tesla / Optimus)

- **色彩:** 近單色石墨(`#16181D`)/ 白;髮絲級線條;**單一紅色強調 `#E82127`**(武裝/告警/CTA);
  冷調鋼藍 `#63A0C4`(L0 監看 / 資訊);琥珀 `#E5A400`(注意)。語意色不單獨承載資訊。
- **字體:** 顯示用粗體緊排;儀表數據一律等寬 + tabular-nums(強化「儀器」感)。
- **留白與精密:** 大留白、薄邊框、克制動效(掃描線/心跳,尊重 `prefers-reduced-motion`)。

## 進入流程(已實作)

`Splash → (首次)介紹頁 → 守護主畫面`,以單一 Activity 的 route 狀態切換(無多餘 Activity 轉場):

- **Splash:** 機器之眼 **Lottie** 開機動畫(旋轉眼窩虛線環 + 紅虹膜環 + 瞳孔收縮 + 掃描線)+
  `CLAUSTRUM` 字標淡入,約 2s 進場。相機**尚未啟動**;此時於背景**預熱** L1 vision 後端。
- **介紹頁:** 三頁可滑動(機器之眼 / Edge AI 隱私 / 即時告警),頁點指示、略過、下一步/開始守護。
  首次完成後以 `SharedPreferences` 記住,再啟動直接進主畫面。
- **進入守護 shell 時才啟動相機**;預熱完成的真 L1 後端(Gemma · LiteRT-LM)進場即就緒。

## 導覽外殼(已實作)

底部四鍵 **單一 Activity** tab 切換(無死路;返回守護相機自動恢復):

| tab | 畫面 | 狀態 |
|---|---|---|
| **守護** | 01 即時守護 · 機器之眼 | ✅ |
| **事件** | 04 事件記錄 | 誠實空狀態(不虛構事件,L2 引擎為 P3) |
| **模型** | 02 模型目錄與下載 | ✅ App 內 gated 下載;切換 L1 為後續 |
| **設定** | L0/L1/加速/隱私/關於 | 唯讀資訊(控制項隨功能落地) |

品牌:App bar 與底部導覽使用機器之眼 `ClaustrumMark`(與 launcher icon 一致);感官卡片內含
`EyeIcon`/`EarIcon`。

## 核心畫面

| # | 畫面 | 重點 |
|---|---|---|
| 01 | **即時守護 · 機器之眼** | 相機框成機器人的**眼睛**(Optimus visor);其**看到/聽到**即時呈現於眼下(擬真);L0→L1 省算力收於底部一行 |
| 02 | **模型目錄與切換** | 多模型瀏覽 + 能力/大小 + App 內下載(進度/續傳)+ **一鍵切換 L1 使用模型**;gated 需 HF 登入 |
| 03 | **主動告警** | 跌倒/暴力嚴重告警;附**畫面內可見證據** + 客觀描述;通知保全 / 誤報回饋;視覺+聲音+震動三通道 |
| 04 | **事件記錄** | 依嚴重度分色時間軸;記錄使用模型(A/B 效果比較);誤報回流壓低錯報 |

## 不變式(貫穿所有畫面)

1. 影格只在裝置端流動、用完即刪;只有**文字描述/事件**可外傳(隱私、PDPA)。
2. L1 只**客觀描述看得到的**;風險/事件判斷屬 L2 且**需畫面內可見證據**(不臆測、抗誤報)。
3. 不同模型效果不同 → **瀏覽與切換模型是一等公民**,並保留替換介面。

## 互動與狀態

- **守護生命週期:** 閒置 → 守護中 → 告警 → 已處理。
- **模型狀態:** 未下載 / 下載中 / 就緒 / 使用中;切換即時生效不需重啟守護。
- **權限:** 相機 / 通知 / 麥克風逐項說明用途後請求;首次啟動先下載一顆 vision 模型。
