把攝影機變成
主動防護的守護者。

在裝置端(edge AI)即時融合視覺與音訊,主動偵測跌倒、暴力等安全事件並當下告警——不是事發後才調閱錄影。此文件在進入完整開發前,先定義產品的介面與互動。設計語彙取 Tesla / Optimus 的精密科技感:近單色石墨、髮絲級線條、留白、單一紅色強調。

核心原則貫穿每一個畫面: ① 影格只在裝置端流動、用完即刪;② L1 只客觀描述看得到的,風險判斷是 L2 的事且必須有畫面內可見證據(不臆測、抗誤報);③ 不同模型效果不同 → 瀏覽與切換模型是一等公民。

原則

  • 可見證據優先:告警一定附畫面來源
  • 抗誤報:寧可少報,錯報是頭號敵人
  • 省算力可見:L0 只在變化時喚醒 L1
  • 模型可換:能力/大小透明,一鍵切換

核心畫面

互動與狀態

守護生命週期

閒置 → 守護中 → 告警 → 已處理。守護中時 L0 每幀跑、僅變化喚醒 L1;告警為可打斷的最高優先。

模型切換

切換即時生效,不需重啟守護。切換前顯示大小/能力/預估延遲;下載中可切到已就緒的模型。狀態:未下載 / 下載中 / 就緒 / 使用中。

抗誤報回饋

每則告警可標記「誤報」,回流調整 L0 閾值與 L2 規則。事件記錄標示模型來源,便於 A/B 不同模型效果。

隱私

影格不離裝置、用完即刪;只有文字描述與事件可外傳到保全。無人物身分特徵留存(PDPA)。

權限與首次啟動

相機 / 通知 / 麥克風(暴力偵測)逐項說明用途後請求。首次啟動先到模型目錄下載一顆 vision 模型。

無障礙與明暗

語意色不單獨承載資訊(附文字/圖示)。深淺色皆為一等公民。告警震動 + 聲音 + 視覺三重通道。
