# ADR-0006 — MVP 重新聚焦:多模態主動安全告警(社區跌倒、幼兒園暴力)

**狀態:** 已接受 · **日期:** 2026-08-06
**釐清/調整:** [ADR-0005](0005-react-native-app.md)(產品形態)、ROADMAP 第二模態閘門、
[ADR-0011](0011-l2-fast-path-evidence.md)(L2 確認用快路徑可見證據；VLM 僅作脈絡)

> **北極星不變**([ADR-0005](0005-react-native-app.md)):即時串流、edge AI、綁定多模態的
> 機器人視覺大腦。本 ADR 只改「第一個垂直與 MVP 範圍」,不改核心架構。

## 背景

先前的框定偏居家照護感知。使用者重新聚焦第一版 MVP 的目標場景與價值:

- **社區**:主動偵測**跌倒** → 通知**保全**支援。
- **幼兒園**:偵測**暴力衝突** → **聲音 + 視覺**主動告警。

並定調:**Phase 2 以手機實機驗證為優先**;**藥袋辨識(ADR/PR #5)延後**(保留不刪);
edge AI 方向不變。

## 決策

**MVP v1 = 裝置端(edge AI)、多模態(視覺 + 音訊)的「主動安全事件偵測與告警」。**
首兩個垂直:社區跌倒 → 通知保全;幼兒園暴力 → 聲光(音+視)告警。

- **音訊提前為第一級模態。** 暴力偵測需要聲音訊號(尖叫、衝突聲)搭配畫面,因此原
  ROADMAP「第二模態(ASR/音訊)延後至 ethogram 過 M6」的閘門,對本 MVP **提前開啟**。
- **核心是並行感知路徑→L2→告警**:輕量 pose/motion/action fast path 直接供 L2 時序判定；
  L0 閘控只替 L1 VLM 節流，L1 客觀描述只能補充脈絡。視覺 + 音訊融合→偵測異常事件→主動告警。跌倒/暴力
  就是 `RiskCategory` 的 `fall` 與(新增)衝突類別。
- **手機驗證優先**:在真機上跑通「感知 → 偵測 → 告警」閉環,優先於先鋪離線管線。

## 理由

- 這兩個場景價值直接(人身安全)、可 demo,且正中 claustrum 的 L0–L2 + 多模態綁定核心。
- 音訊對暴力偵測是必要證據面,提前納入正呼應 claustrum「綁定多模態」的本義。
- 手機優先驗證能最快拿到現實回饋(誤報率、延遲、熱),這正是本專案的關鍵指標所在。

## 安全與倫理(不可省 —— 對象含兒童)

幼兒園場景把鏡頭與麥克風對準**兒童**,倫理與法律敏感度高於一般場景:

- **裝置端完成、不留原始影音**;告警只帶「事件 + 時間 + 地點」,**不外傳影像/聲音原檔**。
- 兒童個資屬高度敏感(PDPA + 更高倫理門檻)—— 部署需機構同意、家長告知、明確治理。
- **暴力/跌倒屬「對外通報」**(驚動保全/園方),誤報代價高:沿用 L2 的抑制紀律
  (去重、速率限制、冷卻),並保留**人工確認**環節;寧可漏抑也不可濫報騷擾。
- 抗幻覺紀律照舊:看不清不臆測;事件需畫面/聲音可見證據才升級告警。

## 後果

- **L2 警示成為 MVP 主軸**:pose 快路徑(recall)+ 確認(precision)。fall recall 與
  false-alerts/24h 就是 MVP 指標。
- App 內要接:**CameraX(視覺)+ 麥克風(音訊)**、**裝置端偵測**(pose/motion/action/聲音事件;
  依 ADR-0011 由快路徑證據確認，VLM 不作唯一 gate)、**告警通道**(通知保全 / 幼兒園端聲光告警)。
- **音訊模組提前**:新增裝置端音訊事件偵測(如尖叫/衝突聲);原第二模態閘門相應調整。
- 醫療/藥袋(schema/prompt/parse/tests 已在 repo)**保留但暫停**,待 MVP 站穩再回頭。
- 需要新增/調整領域型別:`RiskCategory` 增加暴力/衝突類別(schema 變更走既有流程)。

## 重新檢視條件

MVP 在真機驗證跌倒/暴力偵測的召回率與誤報率後,再決定兩垂直的優先序與是否擴場景。
